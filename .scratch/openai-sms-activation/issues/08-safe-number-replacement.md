# 08 — 安全换号并执行三地区获取额度

**What to build:** 号码获取满两分钟且未短信送达时，接收者可二次确认换号。供应商取消成功后自动获取后继号码，整条授权最多使用三个候选地区。

**Blocked by:** 05 — 处理号码获取失败与不确定结果；06 — 通过 Webhook 交付结构化验证码

**Status:** ready-for-agent

- [ ] 两分钟解锁由后端依据 HeroSMS 激活时间判定
- [ ] 换号二次确认默认继续等待，确认后原子进入取消确认中
- [ ] 仅供应商取消明确成功后创建后继激活，退款确认不阻塞换号
- [ ] 取消结果不明确时供应商对账，确认前不创建后继激活
- [ ] 短信与取消竞争以 HeroSMS 最终结果为准，任意时刻最多一个未结束激活
- [ ] 已使用地区不再使用，无库存地区不消耗获取额度
- [ ] 供应商取消后立即删除旧激活的完整号码、验证码和短信正文
- [ ] 第三个供应商激活结束后不允许继续号码获取
- [ ] 取消成功、冲突、过早取消和异常响应的 adapter 契约测试通过
