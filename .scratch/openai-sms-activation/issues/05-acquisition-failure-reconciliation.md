# 05 — 处理号码获取失败与不确定结果

**What to build:** 接收者在无库存或供应商错误后得到可恢复状态；号码获取请求结果不确定时，系统冻结授权并通过专用 HeroSMS 账户对账，避免重复激活。

**Blocked by:** 04 — 完成首次号码获取成功路径

**Status:** ready-for-agent

- [ ] 明确无库存时自动尝试下一个候选地区，全部无库存时保留地区和获取额度
- [ ] 余额、认证、账号限制、参数、限流和供应商错误停止流程且不消耗获取额度
- [ ] 超时、断网或不可解析响应进入获取结果确认中且不盲目重试
- [ ] 活动激活和历史能够恢复唯一归属的供应商激活
- [ ] 无法唯一归属时进入结果待人工对账并暂停全局号码获取队列
- [ ] 管理员可重新执行对账、明确关联一个候选供应商激活，或在确认未产生激活后结束获取请求
- [ ] 人工关联后恢复号码和激活状态；确认未产生激活后清理临时数据并解除全局暂停
- [ ] 管理员处理供应商账户错误后，接收者可在原绑定浏览器重新尝试
- [ ] 应用重启后恢复队列归属和未完成对账
- [ ] 契约与集成测试覆盖每类明确错误和响应丢失场景
