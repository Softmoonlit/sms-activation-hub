# 06 — 通过 Webhook 交付结构化验证码

**What to build:** 系统通过受保护的 HeroSMS Webhook 接收短信。短信送达立即终止换号资格，结构化验证码向仍有访问资格的接收者展示，并完成供应商激活。

**Blocked by:** 04 — 完成首次号码获取成功路径

**Status:** ready-for-agent

- [ ] Webhook 使用秘密路径、来源 IP 白名单、请求限制和激活信息校验
- [ ] 事件持久化后快速返回 200，重复和乱序投递不会重复转换状态
- [ ] 短信送达后立即拒绝取消、换号和后继号码获取
- [ ] 结构化验证码在接收者页面显示并可复制，已绑定浏览器重新打开原链接可恢复验证码
- [ ] `finishActivation` 成功后记录已完成，但不表述或存储“OpenAI 验证成功”
- [ ] 验证码、短信正文和完整号码不进入日志
- [ ] 号码有效窗口结束后删除完整号码、验证码和短信正文
- [ ] Webhook、状态和完成成功响应的 adapter 契约测试通过
- [ ] Playwright 覆盖验证码显示、复制和换号操作消失
