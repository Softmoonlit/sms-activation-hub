# 06 — 通过 Webhook 交付结构化验证码

**What to build:** 系统通过受保护的 HeroSMS Webhook 接收短信。短信送达立即终止换号资格，结构化验证码向仍有访问资格的接收者展示，并完成供应商激活。

**Blocked by:** 04 — 完成首次号码获取成功路径

**Status:** resolved

- [x] Webhook 使用秘密路径、来源 IP 白名单、请求限制和激活信息校验
- [x] 事件持久化后快速返回 200，重复和乱序投递不会重复转换状态
- [x] 短信送达后立即拒绝取消、换号和后继号码获取
- [x] 结构化验证码在接收者页面显示并可复制，已绑定浏览器重新打开原链接可恢复验证码
- [x] `finishActivation` 成功后记录已完成，但不表述或存储“OpenAI 验证成功”
- [x] 验证码、短信正文和完整号码不进入日志
- [x] 号码有效窗口结束后删除完整号码、验证码和短信正文
- [x] Webhook、状态和完成成功响应的 adapter 契约测试通过
- [x] Playwright 覆盖验证码显示、复制和换号操作消失

## Comments

- 实现秘密 Webhook 路径、来源 IP 白名单、每分钟请求限制、16 KiB 请求体限制及激活 ID/服务/地区校验。
- 短信事件按激活 ID、供应商接收时间和负载摘要持久幂等；供应商完成异步执行并可在重启后恢复。
- 接收者页面自动轮询刷新，展示并复制结构化验证码；号码有效窗口结束后清理敏感交付数据。
- 单元与完整集成测试通过；Playwright 用例已补充，但本机缺少 `libnspr4.so`，浏览器无法启动。
