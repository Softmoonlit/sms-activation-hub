# 02 — 配置 HeroSMS 与默认候选地区

**What to build:** 管理员能够查看 HeroSMS 连接和余额，并配置 OpenAI 默认的三个候选地区。设置页展示当前价格与库存，默认值只影响之后创建的激活授权。

**Blocked by:** 01 — 建立可登录的应用骨架

**Status:** ready-for-agent

- [ ] HeroSMS adapter 通过服务端 Secret 查询余额、服务、地区和报价
- [ ] OpenAI 服务代码通过部署配置或已确认供应商数据提供
- [ ] 设置页显示连接状态、余额、地区中文名称、价格和库存
- [ ] 默认候选地区必须恰好三个、互不重复且可查询；瞬时库存不阻止保存
- [ ] 修改默认候选地区不改变已有激活授权
- [ ] API 密钥和完整供应商请求 URL 不进入页面或日志
- [ ] adapter 契约测试覆盖余额、报价、地区、兼容文本和 JSON 成功与错误响应
