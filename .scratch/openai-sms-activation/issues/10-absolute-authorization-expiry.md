# 10 — 执行 24 小时绝对授权到期

**What to build:** 激活授权创建满 24 小时时立即终止接收者访问、删除 token 哈希并返回 404。截止前已经发出的供应商请求继续收尾，但不再交付迟到号码或创建后继激活。

**Blocked by:** 07 — 恢复短信遗漏与处理无法识别的验证码；09 — 处理激活超时并再次获取

**Status:** resolved

- [x] 24 小时到期删除 token 哈希和接收者会话访问能力
- [x] 原授权 URL 在到期后与随机无效地址一样返回 404
- [x] 进入队列不保留期限资格，调用 HeroSMS 前再次检查期限
- [x] 截止前已发出的号码获取请求继续供应商对账
- [x] 截止后才确认成功的号码不交付，并在允许时自动供应商取消
- [x] 截止时已有激活继续处理短信、完成、取消或激活超时，仅管理员可见结果
- [x] 到期后不自动换号或创建后继激活
- [x] 临界秒竞态由真实 PostgreSQL 和可控时钟集成测试覆盖

## Comments

- 授权到期由最近期限定时器触发，并保留分钟扫描和应用重启恢复；到期原子清除 token 哈希与接收者会话哈希。HTTP 入口在截止毫秒同步拒绝访问。
- 截止前发出但截止后才确认成功的供应商激活仍记录费用与地区消耗，但不保存可交付号码，并持久等待两分钟取消窗口后自动供应商取消。正常成功与不确定结果对账共用同一规则。
- 取消确认显式区分主动换号与到期清理；授权到期后会清除待后继标记，不查询报价或创建后继激活。
- 真实 PostgreSQL 与可控时钟测试覆盖截止前 1 毫秒、截止时刻、全局队列跨截止并发、正常迟到成功、不确定结果迟到对账、已有激活继续短信收尾和重启后延迟取消。
- 最终复核 Standards 与 Spec 均无阻塞发现；类型检查、构建、Node 测试 52/52 和 Playwright 1/1 通过。
