# 11 — 按生命周期撤销进行中的激活授权

**What to build:** 管理员根据授权状态和当前激活状态撤销进行中的访问。系统立即切断接收者访问，并对可能存在的激活执行延迟取消、供应商对账或只读收尾。

**Blocked by:** 10 — 执行 24 小时绝对授权到期

**Status:** ready-for-agent

- [ ] 撤销立即切断接收者访问，并统一显示“此链接不可用，请联系发送者”
- [ ] 撤销确认显示接收者标识、双状态、当前地区、获取次数和实际后果
- [ ] 待领取撤销保持票 03 行为并通过回归测试
- [ ] 获取中或结果不明确时先对账，确认号码后尽快供应商取消
- [ ] 等待短信未满两分钟时持久安排最早允许时间的供应商取消
- [ ] 已允许取消时立即请求取消，且绝不自动换号
- [ ] 短信已送达时只终止访问，不尝试供应商取消或期待退款确认
- [ ] 撤销收尾后删除不再需要的敏感交付数据
- [ ] 已结束或已到期授权不显示撤销操作
- [ ] 撤销与短信、取消响应及重启的竞态测试通过
