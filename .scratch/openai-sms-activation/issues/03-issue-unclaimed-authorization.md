# 03 — 创建和撤销待领取激活授权

**What to build:** 管理员填写接收者标识和可选备注，确认预检汇总后创建一个 24 小时激活授权。完整链接只显示一次，尚未领取的授权可撤销。

**Blocked by:** 02 — 配置 HeroSMS 与默认候选地区

**Status:** resolved

- [x] 创建前验证 HeroSMS 连接、余额及三个候选地区的价格和库存
- [x] 确认框汇总接收者标识、三个地区、价格和库存
- [x] 余额低于三个地区当前最高价格或任一地区无库存时阻止创建
- [x] 同一标准化接收者标识最多一条未结束激活授权
- [x] 授权保存三个候选地区快照和固定 24 小时期限，配置不可编辑
- [x] token 至少包含 256 位安全随机值，数据库只保存哈希，完整链接只显示一次并提供复制按钮
- [x] 页面 GET 和链接预览不领取授权，并具备禁止索引与严格 Referrer Policy
