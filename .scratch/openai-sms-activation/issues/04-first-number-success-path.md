# 04 — 完成首次号码获取成功路径

**What to build:** 接收者明确领取授权后绑定当前浏览器。系统按实时报价选择最低价有库存地区，通过全局串行号码获取取得并展示第一个号码。

**Blocked by:** 03 — 创建和撤销待领取激活授权

**Status:** resolved

- [x] 初始移动页面只显示 OpenAI、授权剩余时间和获取号码按钮
- [x] 首次点击原子绑定浏览器，其他浏览器和丢失 Cookie 的会话不能重新绑定并看到统一不可用页面
- [x] 已绑定浏览器在授权到期前重新打开原链接可恢复当前号码和状态
- [x] 候选地区按实时报价排序并选择最低价有库存地区
- [x] 号码获取请求通过 PostgreSQL 全局串行，调用前再次检查授权期限
- [x] 只有取得激活 ID 和号码才消耗候选地区和一次获取额度
