# ADR-0003：待领取链接、领取后时间与持久化兼容模型

- 状态：已接受
- 日期：2026-08-01
- 替代：激活授权“创建后绝对有效 24 小时”的旧时间背景
- 范围：激活授权持久模型与旧 schema 迁移

## 背景

激活授权需要先进入管理员的链接库存，再由接收者明确点击“获取号码”开始使用。创建时绑定接收者、候选地区和 24 小时期限，会让库存链接在发出前无意义地消耗期限，也会保存过早的报价和库存快照。

激活授权和供应商激活仍然是两个独立生命周期。激活授权记录负责链接访问资格和接收者浏览器绑定；供应商激活记录负责号码、短信、取消、完成、超时、退款和对账事实。一个生命周期的状态不能推断另一个生命周期的结果。

## 决策

### 持久模型

`activation_authorizations` 同时兼容旧记录和新模型，新增以下可空字段：

- `token_suffix`：完整 token 的末 8 位，仅用于管理员识别；通过非空部分唯一索引约束，不参与认证。
- `claimed_at`：接收者首次明确获取号码时的领取时间。
- `number_acquisition_expires_at`：领取后允许开始新号码获取的截止时间。
- `result_view_until`：短信结果可查看截止时间。
- `end_prompt_until`：获取额度用尽提示的截止时间。
- `ended_at`、`ended_reason`：已结束事实及其原因。
- `last_activity_at`：最近业务事实或状态变化时间。

`recipient_identifier`、`normalized_recipient_identifier` 和创建阶段的 `expires_at` 改为可空。新待领取链接可以没有接收者标识和创建期限；旧记录继续保存并读取原有值。候选位置的 `quoted_price` 和 `quoted_stock` 改为可空，以便领取后的配置只保存稳定地区事实，旧候选快照仍可读取。

`default_candidate_countries` 增加可空 `country_name`。只有管理员在受控设置流程中解析并保存的名称才是完整名称；旧的仅地区 ID 数据保持名称为空，不能根据地区 ID 猜测或伪造名称。

### 状态兼容

新模型的顶层状态是：

- `unclaimed`：永久待领取；
- `in_progress`：已领取并绑定浏览器；
- `result_available`：结果仍在查看窗口内；
- `ended`：流程已结束，具体原因由 `ended_reason` 记录。

旧的 `sms_delivered`、`quota_exhausted`、`revoked` 和 `expired` 状态继续被 schema 和现有写入路径接受。它们不会在本次迁移中被强制改写，避免历史记录和供应商收尾逻辑失真；后续生命周期切片逐步把新写入收敛到四个新状态。

### 时间边界

待领取记录没有创建阶段的期限。首次领取事务成功后，系统才写入 `claimed_at` 和领取后 24 小时的 `number_acquisition_expires_at`。领取后期限只限制开始新号码获取和创建后继号码；截止前已经取得的当前供应商激活继续使用供应商自己的号码窗口，短信结果查看窗口和额度用尽提示窗口也可以跨过领取后截止点。

这组字段分别表达不可逆的事实，不用一个 `expires_at` 复用多个窗口。后续实现采用半开区间：号码窗口、结果窗口和提示窗口均在各自的截止时刻结束。

### 迁移与安全

初始化 SQL 既负责新数据库建表，也负责历史 schema 升级，并且可以重复执行。迁移会：

- 删除旧的接收者标识、候选快照和创建期限的必填约束；
- 重建包含新旧状态的状态校验；
- 建立 token 哈希和末 8 位的非空唯一索引；
- 为旧撤销、已到期或已结束管理员撤销记录清除 token 哈希和浏览器绑定，确保重启不会恢复访问；
- 为没有历史活动时间的记录回填创建时间作为最低限度的排序基准。

完整 token 只在生成时存在。末 8 位不能从 SHA-256 哈希反推，因此迁移不会伪造旧记录的末 8 位；旧记录允许保持为空。旧撤销和已到期记录保留其历史状态，但迁移会清除 bearer token 哈希，使原链接统一回到标准 404；迁移不会把记录恢复为可领取状态。

## 后果

- 链接库存可以永久停留在待领取状态，不再消耗接收者的业务期限。
- 后续领取实现可以在事务中复制当时完整的候选配置，而无需依赖创建时快照。
- 列表和详情查询必须接受接收者标识、创建期限和候选报价库存为空。
- 旧状态仍会出现在迁移后的历史数据中，管理端和领域代码必须在收敛期间同时理解新旧状态。
- 不能使用 token 哈希或末 8 位恢复完整链接；旧记录没有可重建的 bearer URL。
- 批量创建、领取、分页列表和统一生命周期行为由各自后续切片实现；本决策只提供兼容持久模型，不提前暴露未接通的业务入口。
