# 领域模型

本文描述 OpenAI 短信激活授权的业务对象、生命周期和约束，不规定数据库表、接口或框架实现。

统一术语以根目录 [CONTEXT.md](../CONTEXT.md) 为准。

## 模型关系

一条**激活授权**属于一个接收者标识，并包含恰好三个候选位置；每个位置绑定一个候选地区，不同位置可以绑定相同地区。它可以按顺序产生最多三个**供应商激活**，但任意时刻最多只有一个当前激活。

```text
激活授权
├── 接收者标识
├── 可选内部备注
├── 授权期限
├── 浏览器绑定
├── 3 个候选位置及其候选地区
├── 0..3 个供应商激活
└── 费用与退款记录
```

授权状态与激活状态必须独立。授权到期或撤销后，当前激活仍可能等待短信、收到短信、完成或取消。

## 核心约束

1. 激活授权自创建起绝对有效 24 小时。
2. 进入号码获取队列不取得期限资格；实际调用 HeroSMS 前必须再次检查授权期限。
3. 截止前已发出的号码获取请求必须完成对账，但截止后不再向接收者交付结果。
4. 一条授权恰好包含三个候选位置；每个位置绑定一个候选地区并且最多成功创建一个供应商激活，不同位置允许绑定相同地区。
5. 只有成功取得 HeroSMS 激活 ID 和号码才消耗候选位置与获取额度。
6. 无库存、余额不足、配置错误和未产生激活的请求失败不消耗额度。
7. 一条授权任意时刻最多存在一个未结束的供应商激活。
8. 当前激活取消结果不明确时，不得创建后继激活。
9. 供应商取消一经确认即可换号；退款确认不阻塞换号。
10. 短信一经送达，当前激活不可取消，授权不再产生新激活。
11. 验证码识别只决定能否自动展示，不决定是否允许取消或换号。
12. 短信送达不表示 OpenAI 验证成功。
13. 授权撤销立即终止接收者访问，但不伪造供应商取消结果。
14. 完整号码、验证码和短信正文只在当前流程需要时存在，结束后立即删除。

## 授权状态

| 状态 | 含义 | 是否允许接收者访问 | 是否允许开始号码获取 |
|---|---|---:|---:|
| 待领取 | 链接有效，尚未绑定浏览器 | 是 | 是，首次点击时绑定 |
| 进行中 | 已绑定浏览器，流程尚未产生终局结果 | 是 | 仅无当前激活且有剩余额度时 |
| 短信已送达 | 当前激活已有短信，不能再换号 | 是，直到绝对期限 | 否 |
| 额度已用尽 | 三个候选位置均已产生过激活且没有短信结果 | 是，直到绝对期限 | 否 |
| 已撤销 | 管理员已经终止接收者访问 | 否 | 否 |
| 已到期 | 自创建起已满 24 小时 | 否 | 否 |

授权状态不代替激活状态。例如可以同时存在“授权已到期”和“当前激活等待短信”。

## 当前激活状态

| 状态 | 含义 | 能否创建后继激活 |
|---|---|---:|
| 获取结果确认中 | 号码获取请求结果不明确，正在对账 | 否 |
| 等待短信 | 已取得号码，尚未收到短信 | 否 |
| 取消确认中 | 已请求取消，等待供应商最终结果 | 否 |
| 已取消 | 供应商明确确认取消 | 是，但仍需满足授权期限和额度 |
| 短信已送达 | 已收到短信，结构化验证码可能尚未识别 | 否 |
| 完成确认中 | 已收到短信，供应商完成请求尚未确认 | 否 |
| 已完成 | HeroSMS 已确认完成 | 否 |
| 已超时 | 号码有效窗口结束且未收到短信 | 是，但需要接收者再次点击 |
| 结果待人工对账 | 自动对账无法唯一确定最终结果 | 否 |

“已取消”“已完成”和“已超时”是明确终态。“结果待人工对账”不是终态。

## 号码获取

### 首次获取

1. 接收者在授权期限内点击获取号码。
2. 系统绑定当前浏览器。
3. 系统查询三个未使用候选位置所绑定地区的实时价格与库存并排序。
4. 对最低价有库存地区调用 HeroSMS。
5. 明确无库存时继续下一个地区。
6. 成功取得激活 ID 和号码后，消耗对应候选位置和一次额度。
7. 三个候选位置所绑定的地区均无库存时保留授权与额度，等待接收者联系管理员后重新尝试。

### 主动换号

1. 当前号码获取满 2 分钟且尚未收到短信后，接收者可以请求换号。
2. 接收者二次确认后，系统请求取消当前激活。
3. 供应商确认取消后，立即按剩余候选位置所绑定地区的实时价格顺序获取新号码。
4. 取消结果不明确时停止，不提前获取下一个号码。
5. 短信先于取消到达时停止换号并进入短信送达流程。

### 激活超时

1. 当前激活满 20 分钟且未收到短信时进入超时与退款对账。
2. 系统不自动获取新号码。
3. 授权仍在 24 小时内且有剩余额度时，接收者可以再次点击获取下一个号码。

## 绝对期限

到达授权创建时间加 24 小时时：

- 立即终止接收者访问并删除 token 哈希；原 URL 返回 404。
- 删除浏览器会话绑定的访问能力。
- 不再发起新的号码获取或自动换号。
- 已在截止前发出的 HeroSMS 请求必须继续确认最终结果。
- 截止后才确认买到的号码不向接收者交付，并在允许时自动取消。
- 截止时已有的当前激活继续接收短信，由管理员处理最终结果。
- 当前激活结束后删除完整号码、验证码和短信正文。

## 短信处理

短信到达后立即终止取消和换号资格。

- 有结构化验证码：向仍有访问资格的接收者显示验证码，并异步完成供应商激活。
- 无结构化验证码：接收者页面显示“短信已收到，暂时无法显示验证码，请联系发送者”。
- 管理员可在有效窗口内查看短信正文并人工识别。
- 后续取得结构化验证码时，接收者页面自动改为显示验证码。
- `finishActivation` 失败不阻塞验证码展示，也不重新开放换号。

## 撤销

授权撤销始终先终止接收者访问和后续自动换号。

- 尚未获取号码：直接结束。
- 正在获取或结果不明确：完成对账；若实际取得号码，则尽快取消。
- 等待短信且未满 2 分钟：达到供应商允许时间后自动取消。
- 等待短信且允许取消：立即请求取消。
- 短信已送达：仅终止访问，不再尝试供应商取消或期待退款确认。
- 已结束或已到期：不再提供撤销操作。

## 成本

每个成功供应商激活记录实际激活费用。每笔退款独立确认。

```text
净成本 = 累计激活费用 - 已确认退款
```

供应商取消与退款确认是两个事实：前者允许继续换号，后者只改变财务展示。退款待确认时不能提前减少净成本。

## 敏感数据

敏感交付数据包括完整号码、验证码和短信正文。

- 当前激活需要交付或管理员处理时临时保存。
- 供应商取消、号码有效窗口结束、激活超时收尾或供应商对账完成后立即删除。
- 非敏感历史仅保留接收者标识、候选地区、激活 ID、费用、状态与时间。
- 日志、备份和批量导出不得包含敏感交付数据、完整授权链接或会话凭证。
