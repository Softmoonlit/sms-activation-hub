# 领域模型

本文描述 OpenAI 短信激活授权的业务对象、生命周期和约束，不规定数据库表、接口或框架实现。

统一术语以根目录 [CONTEXT.md](../CONTEXT.md) 为准。

## 模型关系

待领取的**激活授权**只包含访问凭据和创建事实。接收者领取时，激活授权才取得领取期限和当时配置的三至十个候选位置。

```text
待领取激活授权
├── 授权链接
└── 创建时间

已领取激活授权
├── 授权链接
├── 领取期限
├── 3..10 个候选位置及其候选地区
├── 不超过候选位置数的供应商激活
└── 费用与退款记录
```

激活授权状态与激活状态必须独立。激活授权结束后，供应商激活仍可能等待取消、完成或对账。

## 核心约束

1. 完整授权链接是私密 bearer 凭据；任何持有者均可通过任意浏览器查看和操作对应激活授权，系统不识别或绑定浏览器身份。
2. 待领取激活授权永久有效，直到领取或管理员撤销。
3. 领取由首次明确点击获取号码触发；仅打开页面不领取。
4. 领取原子复制当时配置的三至十个候选位置并启动 24 小时领取期限。
5. 候选位置领取后固定；管理员之后修改设置不改变已领取激活授权。
6. 一条已领取的激活授权恰好包含领取时配置的候选位置，不同位置允许绑定相同地区。
7. 只有成功取得 HeroSMS 激活 ID 和号码才消耗候选位置与获取额度。
8. 预算内无可取库存、余额不足、配置错误和未产生激活的请求失败不消耗额度。
9. 一条激活授权任意时刻最多存在一个未结束的供应商激活。
10. 当前激活取消结果不明确时，不得创建后继激活。
11. 供应商取消一经确认即可换号；退款确认不阻塞换号。
12. 短信一经送达，当前激活不可取消，激活授权不再产生新激活。
13. 验证码识别只决定能否自动展示，不决定是否允许取消或换号。
14. 授权撤销立即终止接收者访问，但不伪造供应商取消结果。
15. 完整号码、验证码和短信正文只在当前流程需要时存在，结束后立即删除。

## 激活授权状态

| 状态 | 含义 | 是否允许接收者访问 | 是否允许开始号码获取 |
|---|---|---:|---:|
| 待领取 | 链接有效，尚未领取且没有候选位置 | 是 | 是，首次点击时领取 |
| 进行中 | 已领取，流程尚未产生终局结果 | 是 | 满足期限、额度和当前激活约束时允许 |
| 结果可查看 | 短信已送达，号码和验证码可查看，状态持续至链接 24 小时过期 | 是，只读 | 否 |
| 已结束 | 激活授权已经产生终局结果 | 否；获取额度用尽提示在链接 24 小时过期前仍可访问 | 否 |

结束原因独立记录为：管理员撤销、获取额度用尽或领取期限收尾。结束原因不代替供应商激活状态。

## 库存列表

管理员的最近激活授权列表面向四个顶层状态筛选：待领取、进行中、结果可查看、已结束。收缩迁移收敛的旧记录（旧额度已用尽、旧已撤销、旧已到期）归入已结束展示口径，不恢复任何访问能力。列表支持按授权链接尾号筛选，筛选忽略字母大小写（同一尾号的全部大小写变体一并命中），匹配语义仍为完整尾号相符。

列表按最近业务活动时间倒序，同一时间使用创建时间和记录标识作为稳定次级键，保证跨页不重复不遗漏。创建、领取、号码取得、取消确认、短信送达、完成确认、激活超时、对账、退款确认、异常和结束等真实业务事实推进最近活动时间；没有产生新事实的轮询、重试和只读详情查询不改变顺序。

列表记录只暴露链接末八位、顶层状态和详情入口，不包含接收者标识、候选地区、供应商状态、费用、退款、时间、异常正文或撤销操作。旧撤销历史缺少链接末八位时显示未知标记，不伪造后缀，也不恢复任何访问能力。

## 当前激活状态

| 状态 | 含义 | 能否创建后继激活 |
|---|---|---:|
| 获取结果确认中 | 号码获取请求结果不明确，正在对账 | 否 |
| 等待短信 | 已取得号码，尚未收到短信 | 否 |
| 取消确认中 | 已请求取消，等待供应商最终结果；系统周期对账并重试取消，直至收敛 | 否 |
| 已取消 | 供应商明确确认取消 | 是，但仍需满足领取期限和额度 |
| 短信已送达 | 已收到短信，结构化验证码可能尚未识别 | 否 |
| 完成确认中 | 已收到短信，供应商完成请求尚未确认 | 否 |
| 已完成 | HeroSMS 已确认完成 | 否 |
| 已超时 | 号码有效窗口结束且未收到短信 | 是，但需要接收者再次点击 |
| 结果待人工对账 | 自动对账无法唯一确定最终结果 | 否 |

“已取消”“已完成”和“已超时”是明确终态。“结果待人工对账”不是终态。“取消确认中”也不是终态：系统周期对账，在供应商结果明确或重试取消后收敛；短信已送达的激活按完成收尾，未送达的按取消或人工对账收尾。

## 批量创建

管理员一次创建 1 至 50 条待领取激活授权，默认数量为 10。整批创建全有或全无，不调用 HeroSMS，也不要求当时已经配置候选地区。

完整授权链接只在创建成功时显示一次。长期管理只使用链接末八位作为不可认证的识别标记。

## 默认候选位置配置

1. 管理员维护一份由三至十个有序候选位置组成的当前配置与全局每号最高价（存数据库，默认 0.11），初次配置时默认显示三个位置。
2. 每个位置必须绑定 HeroSMS 当前可查询的候选地区，不同位置允许绑定相同地区。
3. 配置必须完整、连续并一次性保存；任一位置为空或不可查询时，整次保存失败并保留原配置。
4. 减少位置数只移除末尾位置；保存后不保留被移除位置的隐藏历史，再次增加时必须重新选择候选地区。
5. 配置变更影响此后领取的所有待领取激活授权，不改变任何已经领取的激活授权。
6. 系统不保存默认配置的版本历史或提供恢复操作；已领取激活授权保存的候选位置是其业务事实。
7. 候选位置数只决定获取额度，不改变 24 小时领取期限。

## 领取

1. 接收者打开待领取链接时只看到获取号码操作，不显示尚未在领取时确定的获取额度。
2. 首次点击获取号码时，系统原子锁定激活授权。
3. 默认候选位置配置不完整时领取失败并回滚，链接仍为待领取。
4. 配置完整时系统复制全部有序候选位置并启动领取期限；复制的位置数成为该激活授权的获取额度。
5. 两个浏览器并发领取时只初始化一次候选位置和领取期限，并且最多产生一个当前激活；后续请求通过同一授权链接共享当前状态。
6. 领取后的供应商错误或预算内无可取库存不撤销领取，也不消耗获取额度；持有授权链接的接收者可重试。

## 号码获取

1. 后端查询所有未使用候选位置的实时预算内可取库存，不向接收者展示预算内可取库存、默认价或价格。
2. 系统按管理员设置的原始位置顺序尝试当前有预算内可取库存的候选位置，不按价格重新排序。
3. 明确预算内无可取库存时继续下一个位置；被跳过的位置不消耗，后续请求仍按原顺序重新尝试。
4. 成功取得激活 ID 和号码后，消耗对应候选位置和一次额度。
5. 所有位置均预算内无可取库存时保留激活授权与全部额度，页面显示“当前暂无可用号码，请稍后重试”，并在同一行显示“剩余号码获取额度：N · 实际能否获取取决于供应商库存”，等待后续重试。
6. 余额、账户、配置或供应商错误停止当前请求，修复后可通过同一授权链接重试。
7. 获取结果不确定时暂停重试并进行供应商对账。

## 换号与结束使用

1. 当前号码获取满两分钟且尚未收到短信后，接收者可以请求换号。
2. 仍有未使用候选位置时显示“更换号码”；当前号码已经消耗最后一个候选位置时显示“结束使用”。
3. 领取期限届满后仍在有效窗口内的当前号码也只允许“结束使用”。
4. 两种操作均需要二次确认，默认操作为继续等待。
5. 供应商确认取消后，“更换号码”按剩余候选位置顺序获取后继号码；“结束使用”不获取后继号码。
6. 取消结果不明确时停止，不提前获取下一个号码或结束提示。
7. 短信先于取消确认到达时停止取消并进入结果查看期。

## 激活超时

1. 当前激活达到规范化的供应商截止时间且未收到短信时进入超时与退款对账。
2. 系统不自动获取新号码。
3. 供应商确认超时后删除完整旧号码。
4. 仍在领取期限内且有剩余额度时，接收者可点击获取下一个号码。
5. 全部获取额度均已消耗时，页面显示“可用号码次数已用尽，请联系发送者”；提示不设独立期限，链接在 24 小时领取期限内始终可访问。

## 领取期限

领取时刻加 24 小时是开始新号码获取、换号和接收者访问的统一截止点。

- 进入队列不取得期限资格；实际调用 HeroSMS 前必须再次检查领取期限。
- 截止后不再开始号码获取或换号。
- 截止前已经成功取得的当前号码保留供应商原定的号码有效窗口，通常为 20 分钟；可信的供应商截止时间优先，缺失或异常时回退到规范化取得时间加 20 分钟。
- 当前号码越过截止点后，原换号操作降级为结束使用。
- 截止前发出并跨过截止点的请求，以供应商确认的号码取得时间判断能否交付。
- 供应商号码取得时间早于截止点时可以交付，并保留完整号码窗口。
- 供应商号码取得时间等于或晚于截止点时不交付，并在允许时取消。
- 截止时没有当前激活或待确认请求时立即结束访问。
- 结果可查看状态与获取额度用尽提示均随领取期限届满一并结束。
- 当前激活或对账收尾后删除 token 哈希。

## 短信与结果查看

短信送达时间必须早于规范化的号码有效窗口截止时间，才能进入接收者结果查看期；领取期限届满不截断此前已经取得的当前号码窗口。

- 结果查看期不设独立期限：短信送达后进入结果可查看状态，访问资格由 24 小时领取期限统一控制。
- 原号码页面保留地区、完整号码和复制操作，将监听状态替换为验证码结果。
- 结果查看期禁止换号、结束使用和后继号码获取。
- 结果查看期可以越过号码有效窗口截止点，但不越过领取期限。
- 无结构化验证码时显示“短信已收到，暂时无法显示验证码，请联系发送者”，并在链接有效期内继续恢复。
- 领取期限届满时结果查看期结束，删除完整号码、验证码、短信正文和 token 哈希。
- 截止后才送达的短信不恢复接收者访问。

## 接码耗时观测

等待起点与放弃时刻是记录在供应商激活行上的两个观测时刻，用于量化接收者从宣告开始等待到收到短信或放弃号码的耗时。它们只观测，不驱动供应商激活状态转移，不改变取消或换号资格，也不改变两分钟允许取消锚定号码取得时刻的现有规则。

- **等待起点**：接收者取号后在单页流程里点击“点击获取验证码”按钮的瞬间。仅在当前号码处于等待短信且等待起点为空时写入当前时间；重复提交幂等忽略、不覆盖不重置，短信先于按钮到达的号码等待起点留空。该动作不消耗候选位置或获取额度。
- **放弃时刻**：接收者确认换号或确认结束使用、放弃当前正在等待的号码的瞬间。仅接收者主动发起的换号与结束使用确认写入；管理员撤销、授权到期收尾、对账驱动或超时收尾驱动的取消不写，因其并非接收者主动放弃。
- **等待耗时**：短信送达时刻减等待起点为“等多久收到”，放弃时刻减等待起点为“等多久放弃”，均以人读时长展示（满一分钟“等 N 分 M 秒”，不足一分钟“等不到 1 分钟”）。等待起点为空的号码等待起点与耗时均记未记录，短信已送达时仍单独显示送达时刻作为事实佐证；两分钟超时结束、管理员撤销收尾等非接收者主动放弃的号码不套用任何耗时指标。
- **展示互斥**：管理后台详情卡片按送达与否二选一展示——已收到短信的号码只展示等待起点、短信送达时刻与“等多久收到”；未收到短信且被接收者主动换号或结束使用的号码才展示放弃时刻与“等多久放弃”。若号码在系统确认送达前已被接收者主动放弃，放弃时刻数据仍如实保留，只是已送达号码不展示放弃口径，避免“已完成仍显示放弃”的误读。

两个观测时刻不影响号码有效窗口、领取期限与结果查看期，不参与换号或结束使用的资格判断，也不介入两分钟允许取消倒计时与后端放行判断。换号取得后继号码后，新号码等待起点为空，两条号码的等待计时彼此独立。

## 撤销

授权撤销始终立即清理 token 哈希和已保存的敏感交付数据。

- 尚未领取：直接结束。
- 正在获取或结果不明确：继续对账；若实际取得号码，则尽快取消且不交付。
- 等待短信：在供应商允许时取消当前激活。
- 获取结果确认中、结果待人工对账：继续对账，确认供应商激活后在允许时取消，且不重新交付号码。
- 结果可查看：立即停止查看并清理号码和验证码。
- 已结束：不再提供撤销操作；收缩迁移收敛的旧撤销与旧到期记录保持不可访问，历史供应商收尾仍可继续。
- 取消确认后若收到送达时间早于取消确认时间的短信，以短信事实覆盖退款候选，但不恢复已撤销授权的接收者访问。

## 成本与敏感数据

每个成功供应商激活记录实际激活费用，每笔退款独立确认。

```text
净成本 = 累计激活费用 - 已确认退款
```

候选地区不保存领取时的每号最高价、报价和预算内可取库存快照。号码获取请求可以保留对账所需的当次价格，成功激活以供应商返回的实际费用为准。

完整号码、验证码和短信正文只在当前交付、管理员协助或结果对账需要时保存。非敏感历史可保留链接末八位、候选地区、激活 ID、费用、状态与时间。
