# 领域模型

本文描述 OpenAI 短信激活授权的业务对象、生命周期和约束，不规定数据库表、接口或框架实现。

统一术语以根目录 [CONTEXT.md](../CONTEXT.md) 为准。

## 模型关系

待领取的**激活授权**只包含访问凭据和创建事实。接收者领取时，激活授权才取得浏览器绑定、领取期限和恰好三个候选位置。

```text
待领取激活授权
├── 授权链接
└── 创建时间

已领取激活授权
├── 浏览器绑定
├── 领取期限
├── 3 个候选位置及其候选地区
├── 0..3 个供应商激活
└── 费用与退款记录
```

激活授权状态与激活状态必须独立。激活授权结束后，供应商激活仍可能等待取消、完成或对账。

## 核心约束

1. 待领取激活授权永久有效，直到领取或管理员撤销。
2. 领取由首次明确点击获取号码触发；仅打开页面不领取。
3. 领取原子绑定当前浏览器、复制当时配置的三个候选位置并启动 24 小时领取期限。
4. 候选位置领取后固定；管理员之后修改设置不改变已领取激活授权。
5. 一条激活授权恰好包含三个已领取后的候选位置，不同位置允许绑定相同地区。
6. 只有成功取得 HeroSMS 激活 ID 和号码才消耗候选位置与获取额度。
7. 无库存、余额不足、配置错误和未产生激活的请求失败不消耗额度。
8. 一条激活授权任意时刻最多存在一个未结束的供应商激活。
9. 当前激活取消结果不明确时，不得创建后继激活。
10. 供应商取消一经确认即可换号；退款确认不阻塞换号。
11. 短信一经送达，当前激活不可取消，激活授权不再产生新激活。
12. 验证码识别只决定能否自动展示，不决定是否允许取消或换号。
13. 授权撤销立即终止接收者访问，但不伪造供应商取消结果。
14. 完整号码、验证码和短信正文只在当前流程需要时存在，结束后立即删除。

## 激活授权状态

| 状态 | 含义 | 是否允许接收者访问 | 是否允许开始号码获取 |
|---|---|---:|---:|
| 待领取 | 链接有效，尚未绑定浏览器且没有候选位置 | 是 | 是，首次点击时领取 |
| 进行中 | 已绑定浏览器，流程尚未产生终局结果 | 是 | 满足期限、额度和当前激活约束时允许 |
| 结果可查看 | 短信已送达，号码和验证码处于五分钟只读查看期 | 是，只读 | 否 |
| 已结束 | 激活授权已经产生终局结果 | 否；额度提示期除外 | 否 |

结束原因独立记录为：管理员撤销、结果查看期结束、获取额度用尽或领取期限收尾。结束原因不代替供应商激活状态。

## 当前激活状态

| 状态 | 含义 | 能否创建后继激活 |
|---|---|---:|
| 获取结果确认中 | 号码获取请求结果不明确，正在对账 | 否 |
| 等待短信 | 已取得号码，尚未收到短信 | 否 |
| 取消确认中 | 已请求取消，等待供应商最终结果 | 否 |
| 已取消 | 供应商明确确认取消 | 是，但仍需满足领取期限和额度 |
| 短信已送达 | 已收到短信，结构化验证码可能尚未识别 | 否 |
| 完成确认中 | 已收到短信，供应商完成请求尚未确认 | 否 |
| 已完成 | HeroSMS 已确认完成 | 否 |
| 已超时 | 号码有效窗口结束且未收到短信 | 是，但需要接收者再次点击 |
| 结果待人工对账 | 自动对账无法唯一确定最终结果 | 否 |

“已取消”“已完成”和“已超时”是明确终态。“结果待人工对账”不是终态。

## 批量创建

管理员一次创建 1 至 50 条待领取激活授权，默认数量为 10。整批创建全有或全无，不调用 HeroSMS，也不要求当时已经配置候选地区。

完整授权链接只在创建成功时显示一次。长期管理只使用链接末八位作为不可认证的识别标记。

## 领取

1. 接收者打开待领取链接时只看到获取号码操作。
2. 首次点击获取号码时，系统原子锁定激活授权。
3. 三个候选位置配置不完整时领取失败并回滚，链接仍为待领取。
4. 配置完整时系统复制三个有序候选位置、绑定当前浏览器并启动领取期限。
5. 两个浏览器并发领取时只有第一个成功，后续浏览器不能重新绑定。
6. 领取后的供应商错误或无库存不撤销领取，也不消耗获取额度；原浏览器可重试。
7. 浏览器绑定丢失后不能恢复，管理员只能撤销并重新发放链接。

## 号码获取

1. 后端查询三个未使用候选位置的实时库存，不向接收者展示库存或价格。
2. 系统按管理员设置的原始位置顺序尝试当前有库存的候选位置，不按价格重新排序。
3. 明确无库存时继续下一个位置；被跳过的位置不消耗，后续请求仍按原顺序重新尝试。
4. 成功取得激活 ID 和号码后，消耗对应候选位置和一次额度。
5. 三个位置均无库存时保留激活授权与额度，等待原浏览器重试。
6. 余额、账户、配置或供应商错误停止当前请求，修复后可由原浏览器重试。
7. 获取结果不确定时暂停重试并进行供应商对账。

## 换号与结束使用

1. 当前号码获取满两分钟且尚未收到短信后，接收者可以请求换号。
2. 前两个号码显示“更换号码”；最后一个号码显示“结束使用”。
3. 领取期限届满后仍在有效窗口内的当前号码也只允许“结束使用”。
4. 两种操作均需要二次确认，默认操作为继续等待。
5. 供应商确认取消后，“更换号码”按剩余候选位置顺序获取后继号码；“结束使用”不获取后继号码。
6. 取消结果不明确时停止，不提前获取下一个号码或结束提示。
7. 短信先于取消确认到达时停止取消并进入结果查看期。

## 激活超时

1. 当前激活达到规范化的供应商截止时间且未收到短信时进入超时与退款对账。
2. 系统不自动获取新号码。
3. 供应商确认超时后删除完整旧号码。
4. 仍在领取期限内且有剩余额度时，接收者可点击获取下一个号码。
5. 三个获取额度均已消耗时，页面显示两分钟“可用号码次数已用尽，请联系发送者”，随后结束访问。

## 领取期限

领取时刻加 24 小时是开始新号码获取和换号的截止点。

- 进入队列不取得期限资格；实际调用 HeroSMS 前必须再次检查领取期限。
- 截止后不再开始号码获取或换号。
- 截止前已经成功取得的当前号码保留供应商原定的号码有效窗口，通常为 20 分钟；可信的供应商截止时间优先，缺失或异常时回退到规范化取得时间加 20 分钟。
- 当前号码越过截止点后，原换号操作降级为结束使用。
- 截止前发出并跨过截止点的请求，以供应商确认的号码取得时间判断能否交付。
- 供应商号码取得时间早于截止点时可以交付，并保留完整号码窗口。
- 供应商号码取得时间等于或晚于截止点时不交付，并在允许时取消。
- 截止时没有当前激活或待确认请求时立即结束访问。
- 当前激活或对账收尾后删除 token 哈希和浏览器绑定。

## 短信与结果查看

短信送达时间必须早于规范化的号码有效窗口截止时间，才能进入接收者结果查看期；领取期限届满不截断此前已经取得的当前号码窗口。

- 结果查看期从供应商报告的短信送达时间起计算五分钟。
- 原号码页面保留地区、完整号码和复制操作，将监听状态替换为验证码结果。
- 结果查看期禁止换号、结束使用和后继号码获取。
- 结果查看期可以越过号码有效窗口和领取期限截止点。
- 无结构化验证码时显示“短信已收到，暂时无法显示验证码，请联系发送者”，并在剩余时间继续恢复。
- 结果查看期结束后删除完整号码、验证码、短信正文、token 哈希和浏览器绑定。
- 截止后才送达的短信不恢复接收者访问。

## 撤销

授权撤销始终立即清理 token 哈希、浏览器绑定和已保存的敏感交付数据。

- 尚未领取：直接结束。
- 正在获取或结果不明确：继续对账；若实际取得号码，则尽快取消且不交付。
- 等待短信：在供应商允许时取消当前激活。
- 结果可查看：立即停止查看并清理号码和验证码。
- 已结束：不再提供撤销操作。

## 成本与敏感数据

每个成功供应商激活记录实际激活费用，每笔退款独立确认。

```text
净成本 = 累计激活费用 - 已确认退款
```

候选地区不保存领取时的报价和库存快照。号码获取请求可以保留对账所需的当次价格，成功激活以供应商返回的实际费用为准。

完整号码、验证码和短信正文只在当前交付、管理员协助或结果对账需要时保存。非敏感历史可保留链接末八位、候选地区、激活 ID、费用、状态与时间。
